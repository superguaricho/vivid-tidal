* Overview
=vivid-tidal= is a bridge between *Vivid* (Haskell SuperCollider DSL) and *TidalCycles*. It allows you to define SuperCollider =SynthDef=s using the Vivid DSL and seamlessly use them in your live coding sessions with Tidal.

This project focuses on providing a robust synchronization mechanism between the Haskell creative environment and the SuperCollider audio server.

* Architecture: Three-Layer Synchronization
The core of this project is a sound synchronization mechanism that connects three distinct layers:

1. **/Haskell (Vivid)/**: The creative layer where SynthDefs are defined using Vivid. It handles the persistence of definitions to disk and notifies the other layers.
2. **/scsynth (Audio Server)/**: The real-time engine that receives binary SynthDefs and generates sound.
3. **/sclang (SuperDirt)/**: The interpreter that acts as the “brain” for TidalCycles. It maintains a dictionary of instruments and maps Tidal patterns to server commands.

** Features
- *Standard SuperDirt Integration*: Automatically maps Tidal parameters (=freq=, =sustain=, =pan=) to Vivid UGens.
- *Hot-Reloading*: Sends =SynthDef=s directly to the server and notifies =sclang/SuperDirt= to register them instantly.
- *Persistence*: Writes =.scsyndef= files to the SuperCollider directory (~/.local/share/SuperCollider/synthdefs/~) so SuperDirt can read parameter metadata.
- *Cymbal Synthesis*: Includes an advanced implementation of Dan Stowell's cymbal model.

** Prerequisites
- *Haskell*: GHC 9.6.x (via =cabal=).
- *SuperCollider* with the *SuperDirt* quark installed.
- *TidalCycles* (Haskell library) for pattern sequencing.

** Usage Workflow
1. *Boot SuperCollider*: In a terminal run =superdirt_start.scd= in SC:

   #+begin_src sh
   cd /path/to/vivid-tidal
   sclang superdirt_start.scd
   #+end_src

2. *Start GHCI*: In other terminal:

   #+begin_src sh
   cd /path/to/vivid-tidal
   cabal repl
   #+end_src

3. **Boot the Environment**: Execute =:boot= in the GHCi session. This loads all modules (including Cymbals), defines all custom parameters (~pF~), and starts Tidal.

4. **Play**: Try your first pattern:
   #+begin_src tidal
   d1 $ s "vividCymS*4" # sustain 0.5
   #+end_src

** Troubleshooting
If GHCi shows a warning like =*** WARNING: . is writable by someone else, IGNORING!=, it means the directory permissions are too open for GHCi's security policy. You can fix this by running:
#+begin_src sh
chmod go-w . .ghci
#+end_src
